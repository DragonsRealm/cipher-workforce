## Artifact contract

- `specs/*.json` is the source of truth for components, directed relationships, exact labels, evidence paths, layout, and prompt additions.
- `prompt-pack.md` is generated from those specs and contains one dark generation prompt plus light-theme edit and repair prompts for every diagram.
- `drafts/{dark,light}/*.png` contains project-bound GPT Image drafts. They are references, not authoritative architecture documentation.
- `manifest.json` records the frozen source snapshot and per-diagram validation state.
- `validation-report.json` is generated by the validator.
- `visual-review.md` records the full-resolution and README-width inspection matrix.
- `docs/diagrams/v2/{dark,light}/*.svg` contains the editable authoritative diagrams. Existing public diagrams remain unchanged.

All diagrams use a `1920 × 1080` viewBox. Dark and light variants share one geometry specification.
